## Sobre mi

Soy **Full Stack Developer** con experiencia profesional construyendo y evolucionando aplicaciones web en producción.

Mi enfoque principal está en **React + TypeScript** para frontend y en **C#/.NET** o **Node.js/Express** para backend, trabajando con **PostgreSQL**, APIs REST, autenticación, reglas de negocio y despliegue sobre infraestructura Linux/AWS.

Me desenvuelvo especialmente bien en proyectos donde puedo participar en el ciclo completo: **requerimientos → diseño de flujo → base de datos → backend → frontend → pruebas → despliegue y mantenimiento**.

Actualmente también desarrollo **AcaBeck / FitAdminPro**, un proyecto independiente para gestión de gimnasios donde soy responsable principal del frontend y de la infraestructura cloud, además de crear y adaptar endpoints .NET cuando el producto lo requiere.

## Experiencia que mejor representa mi perfil

### Gobierno del Estado de Hidalgo — Full Stack Developer

Trabajo sobre múltiples sistemas internos, principalmente con **React, Node.js/Express y PostgreSQL**, participando de extremo a extremo en funcionalidades y proyectos asignados.

- Desarrollo y mantenimiento de sistemas en producción con contacto directo con usuarios finales.
- Construcción de APIs REST, interfaces administrativas, dashboards, formularios y flujos con reglas de negocio.
- Implementación de **WebSockets** y **Firebase Cloud Messaging** para comunicación y notificaciones en tiempo real.
- Implementación completa de **2FA/TOTP**, incluyendo enrolamiento por QR y adaptación del flujo de login.
- Migración de datos **MongoDB → PostgreSQL** mediante Python, con limpieza, deduplicación y normalización relacional.
- Evolución de sistemas productivos de gestión de proyectos, inventario tecnológico y servicios clínicos internos.

### JC&JF Cargo — Desarrollador .NET

Estuve a cargo de la evolución de un **módulo operativo de cajas**, separado del sistema empresarial principal y desarrollado con **ASP.NET Core MVC / .NET 6**, **Entity Framework Core** y **SQL Server**.

- Modifiqué procesos de revalidación, tránsito, validación/salidas, previos y generación de tickets.
- Ajusté flujos a partir de pruebas y retroalimentación de usuarios especialistas.
- Integré una biblioteca de CFDI dentro del flujo de facturación.
- Trabajé también con componentes legacy en **ASP.NET Web Forms / .NET Framework** y adaptación de reglas de negocio hacia soluciones .NET más modernas.

### AcaBeck / FitAdminPro — Proyecto independiente

Plataforma de gestión para gimnasios desarrollada con **.NET 8, React, TypeScript y PostgreSQL**.

- Arquitectura frontend modular por dominios, hooks, services, mappers y capa HTTP reutilizable.
- Autenticación mediante JWT en cookies HttpOnly, rutas protegidas y restauración de sesión.
- Arquitectura multi-tenant con selección dinámica de conexión por `DatabaseId` y una base PostgreSQL por gimnasio.
- Infraestructura en **AWS EC2**, Docker Compose, Nginx, DNS y SSL/TLS con Certbot.
- Validación con un gimnasio piloto que actualmente administra información de aproximadamente **110 miembros**.
