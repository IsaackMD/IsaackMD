## Sobre mi

Soy **Full Stack Engineer** enfocado en construir sistemas web mantenibles, escalables y listos para produccion. Trabajo principalmente con **.NET/C#**, **Node.js**, **React**, **TypeScript**, **PostgreSQL**, **AWS**, **Docker** y **Nginx**.

Me interesa resolver problemas completos: backend, frontend, arquitectura, base de datos, despliegue e infraestructura. Aplico **Clean Architecture**, **DDD**, **CQRS**, **SOLID**, **Unit of Work** y patrones de desacoplamiento cuando realmente aportan claridad y mantenibilidad.

Actualmente tambien desarrollo **AcaBeck**, una plataforma SaaS propia para gestion de gimnasios, donde llevo el producto end-to-end: arquitectura, infraestructura, despliegue, operacion y validacion con cliente piloto.
